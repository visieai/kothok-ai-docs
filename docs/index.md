# Kothok AI developer documentation

This site is the integration reference for developers connecting a site to Kothok AI.
It covers two tasks:

1. **Add the chat widget** to a website.
2. **Send a product catalogue** so the assistant can search it.

Everything here is done from your own code or the dashboard. You do not need access
to anything internal.

## Where to start

- [Developer guide overview](developer/overview.md) — the two tasks and how they fit.
- [Install the widget](widget/install.md) — the one script tag and its options.
- [Import methods](developer/import-methods.md) — the four ways to send products in.
- [Product API](developer/push-api.md) — send products over HTTP.

## Get your keys

Your **public key** (for the widget) and any **ingest token** (for the product API)
come from the dashboard. See each page for the exact place to find them.
