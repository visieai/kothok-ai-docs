# Discount codes

If you have a discount code, you can use it when you change your plan or buy an
add-on.

## Use a code

1. Open the **Billing** page in the dashboard.
2. Choose a plan or add-on.
3. Enter your code in the discount box.
4. Check that the discount is applied to the amount, then pay. See [How to pay](payments.md).

**Result:** the discount is taken off your total before you pay.

## Good to know

* A code is checked as you type it, so you know right away whether it is valid.
* A code can give a percentage off or a fixed amount off.
* Some codes work only in one currency. If a code does not apply, check whether it is
  meant for BDT or USD.
* Codes can have limits — for example, a limited number of uses per account. If a
  code stops working, it may have reached its limit.

## A code does not work?

* Make sure you typed it exactly, with no extra spaces.
* Check that it matches your currency.
* If it still fails, contact [Support](../support.md).
